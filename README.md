# Student Grade Calculator

This is a simple Python project made to calculate the marks and grade of a student.

## What it does

* Takes marks of different subjects
* Calculates total marks
* Calculates percentage
* Shows the grade

## Language Used
python

## How to run 

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder.
4. Open the terminal in the project folder.
5. Run the following command:
6. python student_grade_calculator.py
7. Enter the student's name and marks when the program asks for them.
8. The program will show the total marks, percentage, and grade.

## Example


Enter marks for 5 subjects:

Subject 1: 80
Subject 2: 75
Subject 3: 90
Subject 4: 70
Subject 5: 85

Total Marks: 400
Percentage: 80.0%
Grade: A
