# Student Grade Calculator

This is a simple Python project made to calculate the marks and grade of a student.

## What it does

* Takes marks of different subjects
* Calculates total marks
* Calculates percentage
* Shows the grade

## Language Used

* Python

## Example


Enter marks for 5 subjects:

Subject 1: 80
Subject 2: 75
Subject 3: 90
Subject 4: 70
Subject 5: 85

Total Marks: 400
Percentage: 80.0%
Grade: A


## Concepts Used

I used some basic Python concepts in this project:

* Variables
* Input and output
* Arithmetic operations
* If-else conditions

## About the Project

I made this project to practice the basic concepts of Python and understand how marks and grades can be calculated using a simple program.
